# 1.2.1 ストア文言の案

**採用（2026-10-11）：サブタイトル 案3、プロモーション用テキスト 案B。** `subtitle-ja.txt` / `promotional-text-ja.txt` に反映済み。申請は 1.2.0 の承認後。

App Store Connect の 1.2.1 に登録する前の候補です。採用する案を選んでください（プロモーション用テキストは審査なしで、いつでも差し替えられます）。

## サブタイトル（30字以内）

1. 編み込み模様の編み図と段数カウンター（18字）
2. 編み込み模様をつくって、編み地で確認（18字）
3. 写真から編み込み模様・段数カウンター（18字）

おすすめ：1。「編み込み模様」が先頭に来て、何のアプリかが検索結果の1行で伝わります。今の「写真から編み図・段数カウンター」は写真機能を推しますが、編み込みのアプリだと分かりにくいです。

## プロモーション用テキスト（170字以内・審査なしで変更可）

### 案A（99字）

7日間、すべての機能を無料で。編み込み模様の編み図づくり、写真からの柄づくり、編み地プレビュー、段数カウンターまでひとつのアプリで。体験後は3,000円の買い切りで、自動課金・月額料金はありません。

### 案B（92字）

推しやペット、家族の写真を2〜3色の編み込み模様に。編み図と編み地プレビューで仕上がりを確かめながら、段数カウンターで一段ずつ迷わず編めます。7日間無料で全機能を試せて、自動課金なし。

案Aは「7日間無料・買い切り」の安心感を、案Bは写真機能の楽しさを前面に出しています。

## 説明文の冒頭3行（「さらに見る」を押さなくても見える部分）

```
編み込み模様を、描いて、確かめて、一段ずつ編み進める。
写真から2〜3色の編み図をつくり、V字の編み地プレビューで仕上がりを確認。段数カウンターで、今編んでいる段を見失いません。
7日間すべての機能を無料でお試しいただけます。その後は3,000円の買い切りで、自動課金・月額料金はありません。
```

（1行目 27字／2行目 61字／3行目 56字）

今の冒頭は「ひと目ずつ描いて、編み地を確かめながら編み進める。」「『編みものノート』は、棒針編み込みの…まとめたアプリです。」で、写真機能と無料体験が「さらに見る」の先に隠れています。案では2行目で写真機能とプレビュー、3行目で無料体験と自動課金なしを伝えます。4行目以降は今の説明文（■ NEW 写真から…以降）をそのまま続けます。
