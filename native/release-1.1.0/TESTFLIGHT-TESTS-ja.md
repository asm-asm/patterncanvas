# 1.1.0（29.1）購入機能の最終確認

TestFlightの購入はテスト環境で、実際の請求はありません。App Storeで配信中の版と区別してください。TestFlightでは旧有料版の購入済み判定をせず、新しい購入フローを確認できます。

1. 事前に「設定・保存」から作品を書き出してバックアップします。
2. TestFlightで1.1.0（29.1）へ更新します。
3. 「設定・保存 → 利用状況・購入を確認」で、7日間・体験後の制限・買い切り価格・自動課金なしの説明を確認します。
4. 「7日間の無料体験を開始」を選び、Appleの確認画面で0円を確認して開始します。編集・段数カウンターが使えることを確認します。
5. アプリを終了・再起動して体験終了日時が同じことを確認します。体験中に「購入を復元」を押しても日時が延びないことを確認します。
6. 「3,000円で永久解除」を押して一度キャンセルします。永久解除済みにならないことを確認します。
7. 再度永久解除のテスト購入を行い、再起動・復元後も永久解除済みになることを確認します。
8. 機内モードで再起動し、確認済みの利用権限と作品が残ることを確認します。初回体験開始・購入・復元にはネット接続が必要です。

無料体験終了の7日境界と閲覧・書き出しの維持は自動テストでも確認しています。実機のオフライン再起動、Apple Accountの変更、Apple確認画面でのキャンセルは最終実機確認が必要です。作品は端末内保存のため、購入復元だけでは別端末へ作品は移りません。

初回アプリ内購入2商品の同時審査と1.1.0の承認が完了するまで、公開中の価格を変更しないでください。
