# 編みものノート App Store提出素材

販売方針：日本のみ／買い切り3,000円／iPhone・iPad。

## 入力する場所
| ファイル | App Store Connectの入力先 |
|---|---|
| description-ja.txt | 配信 → iOSバージョン → 説明 |
| promotional-text-ja.txt | プロモーション用テキスト |
| keywords-ja.txt | キーワード |
| subtitle-ja.txt | App情報 → 日本語 → サブタイトル |
| review-notes-en.txt | App Reviewに関する情報 → メモ |
| screenshots/iphone-store.png | iPhone 6.9インチのスクリーンショット枠 |
| screenshots/ipad-store.png | iPad 13インチのスクリーンショット枠 |
| metadata-ja.json | 設定値一覧（そのまま一括アップロードする形式ではありません） |
| privacy-and-rating-ja.md | プライバシー・年齢制限の回答確認用 |
| submission-checklist-ja.md | ご本人の入力・実機確認と提出手順 |

登録名は「編みものノート」に統一します。現在のApple登録は「編み物ノート」です。
価格はApp Store Connectで設定します。ストア説明文には価格を固定記載せず、購入価格はAppleの価格表示に任せます。
審査連絡先と著作権名は推測で埋めていません。

スクリーンショットはシミュレーターの実画面です。capture.jsonに撮影元のソースと端末を記録します。広告用の合成画像ではありません。
正式審査への提出と販売開始はまだ行っていません。
