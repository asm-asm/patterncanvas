# 公開前に残っていること

販売価格：日本向け買い切り3,000円。素材の生成時点では価格をAppleに登録していません。
提出候補：1.0.0（14.1）。App Storeの登録状態は「提出準備中」、バージョン1.0、ビルド未選択です。

## 用意したもの
- description-ja.txt：説明文
- promotional-text-ja.txt：プロモーション用テキスト
- subtitle-ja.txt：サブタイトル
- keywords-ja.txt：100バイト以内の検索キーワード
- review-notes-en.txt：審査担当者向け説明（ログイン不要）
- screenshots/：最新版のiPhone・iPadシミュレーターで撮影した実画面

## ご本人の確認・入力が必要
- 銀行口座：設定完了との申告あり。有料アプリ契約と税務情報も有効か確認。
- 著作権欄の正式な権利者名（2026＋氏名または法人名）。こちらでは推測しません。
- 審査連絡先：実在する氏名・メール・電話番号をAppleに直接入力。
- 販売地域は日本のみ、ストア表示名は「編みものノート」で確定。Apple側の現在名「編み物ノート」から変更する。
- プライバシー回答案：開発者によるデータ収集なし。提出対象のSDK・Privacy Manifestと最終照合。
- 年齢レーティング質問票：広告、チャット、公開投稿、賭博、成人向けコンテンツ、健康助言なし。画像選択・固定サポートリンクは実装に即して回答。年齢を独自に確定しない。
- アクセシビリティ表示：実機で検証済みの項目だけを申告。
- 実機iPhone/iPadで14.1のダブルタップ、画像取り込み、保存→終了→再起動、JSON書き出し・再読込を確認。

## App Store Connectへ入力
1. 日本向け価格3,000円、販売地域を設定。
2. 掲載テキスト・スクリーンショット・URLを登録。
3. ビルド14.1を選択し、登録バージョンとの整合を確認。
4. 公開方法は手動リリースを推奨（現状は承認後自動公開）。
5. 必須回答と実機確認の完了後、正式審査へ提出。

このパッケージ作成だけでは、審査提出や販売開始は行いません。
